# FreshBox Landing Page — Homework Requirements

Use these requirements to test the FreshBox page.

1. The main font on the page must be **Inter**.
2. All form fields must use the same font as the main page font: **Inter**.
3. The logo color must be **#16A34A**.
4. The primary CTA button `Order now` must have background color **#16A34A**.
5. Product card buttons must have background color **#16A34A**.
6. Submit button must have background color **#16A34A**.
7. All visible texts must be spelled correctly.
8. Email input placeholder must say: **Enter your email address**.
9. Benefit text must say: **Eco-friendly packaging for every order.**
10. The page should be readable on desktop and mobile.
